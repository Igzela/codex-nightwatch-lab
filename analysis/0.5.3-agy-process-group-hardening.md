## 1. Executive Summary

Nightwatch 0.5.3 delivers the final process-group hardening closure for Google Antigravity (AGY) provider turns. This release resolves critical process containment boundaries, state validation and legacy migration rules, descendant lifetime isolation, and documentation bookkeeping.

### Core Architectural Closures:

1. **P1 — Dedicated Process Group & Group Abort Containment**:
   - Spawns AGY provider turns with `start_new_session=True` (Linux-native `setsid`).
   - Verifies `pgid == leader_pid` and `pgid != os.getpgrp()`. Nightwatch supervisor is never placed in the child process group.
   - Replaces leader-only termination with `_abort_process_group(pgid, process, grace_seconds=0.5)` which escalates `SIGINT` -> `SIGTERM` -> `SIGKILL` across the entire process group using `os.killpg()`.
   - Applied to all AGY abort paths: conversation ID mismatch on init, later stream mismatch on `step_update`/`result`, watchdog/print timeouts, and manual supervisor stop requests.
   - Proves ordinary descendant processes (such as child commands spawned by AGY) do not survive abort events.

2. **P2 — State Validation & Legacy Timeout Migration**:
   - `validate_state()` in `models.py` validates `agy_print_timeout` on AGY provider state (fails closed on non-string, boolean, malformed syntax, `<5s`, or `>24h`).
   - Explicitly rejects non-null `agy_print_timeout` on Codex state.
   - `load_state()` in `storage.py` detects legitimate legacy AGY states missing `agy_print_timeout`, automatically migrates them to `"60m"`, and persists the migration durably to disk via atomic write.
   - Malformed present timeouts fail closed and are not migrated. Missing timeout on Codex state continues to load cleanly.

3. **P3 — Historical CI Evidence Bookkeeping Correction**:
   - Corrected `analysis/0.5.2-final-agy-closure-report.md` to accurately document both the initial passing PR head (`fe1052f`, Run `#33875917031`), the final PR head with the closure report (`589aa4f`, Run `#33876228653`), and the post-merge master commit (`a26e65e`, Run `#33876466054`).

4. **Preservation of Codex Semantics & Frozen Decisions**:
   - `start_new_session=True` remains strictly AGY-specific; Codex process semantics, rotation, and account pool handling are 100% preserved.
   - Owner-approved unattended permission policies and fail-closed security invariants remain intact.
