## 1. Executive Summary

Nightwatch 0.5.1 closes all production-readiness, quota-accounting, stream-contract, and systemd-supervision gaps identified during initial AGY operations. The release elevates Google Antigravity CLI (AGY) from an initial provider prototype into a fully verified, long-running, production-hardened provider.

### Core Deliverables:
1. **Model-Aware Quota Mapping**:
   - `/usage` output parsed into family-specific buckets: `Gemini Models` (`gemini-5h`, `gemini-weekly`) and `Claude and GPT models` (`3p-5h`, `3p-weekly`).
   - Models prefixed with `gemini-*` map strictly to Gemini buckets; `claude-*`, `gpt-*`, and `gpt-oss-*` map strictly to 3P buckets.
   - Unknown model slugs fail closed immediately (`ValueError`).
   - Quota snapshots validate bucket presence, parse resets, and ensure remaining fractions satisfy 0.0 <= f <= 1.0.
2. **Normal Quota Cycles vs. Abnormal Recovery Failures**:
   - Normal quota waits and recoveries increment `quota_cycles` and `recoveries` without artificial caps.
   - Circuit breaker (`MAX_RECOVERY_FAILURES = 3`) is consumed *only* by consecutive abnormal failures (unparseable `/usage`, missing buckets, network/auth errors during probe, or repeated crashed revalidation).
   - Proven safe for 100+ consecutive clean quota cycles without tripping.
3. **Real Systemd Execution & Exact Conversation Resume Gate**:
   - Live execution through `systemctl --user` on host `charlie` inside a disposable repo.
   - Multi-turn execution verified under systemd: Turn 1 captures conversation ID, Turn 1 fails verification, Turn 2 resumes exact same conversation ID (`--conversation <UUID>`), Turn 2 passes verification, reaches `DONE`, service exits with `status=0/SUCCESS`.
   - Complete transient unit cleanup verified.
4. **Authoritative Start-Turn Stream Contract**:
   - `init` event captures conversation identity X. Every subsequent event (`step_update`, `result`) must match X.
   - Any ID mismatch, missing `init` on start turn, or non-terminal/unknown result status fails closed with `ErrorKind.STATE`.
5. **Terminal Status Semantics & Strict Precedence**:
   - Precedence: Quota (`QUOTA_5H` / `QUOTA_WEEKLY`) -> Auth (`AUTH`) -> Missing init on start (`STATE`) -> Malformed JSONL (`MALFORMED`) -> Result status (`CANCELED`, `INTERRUPTED`, `WAITING`, `RUNNING`, `ERROR`, `SUCCESS`, unknown) -> Process crash without result event.
   - Word-boundary matching prevents false positives on goal hashes or message text containing digit sequences like `429`.
6. **Owner-Approved Unattended Permission Policy**:
   - Explicitly preserves `--dangerously-skip-permissions` for unattended supervised AGY provider turns.
   - Documented in code as `OWNER_APPROVED_UNATTENDED_AGY_PERMISSION_POLICY`.
