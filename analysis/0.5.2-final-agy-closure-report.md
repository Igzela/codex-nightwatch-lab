## 1. Executive Summary

Nightwatch 0.5.2 delivers the definitive closure mission for Google Antigravity (AGY) provider integration in Nightwatch. This release resolves critical foreground execution, fail-closed process safety, quota authority, long-turn execution, and provider-aware instruction transport issues.

### Core Architectural Closures:
1. **P1-A — Foreground Inhibit Provider & Timeout Preservation**:
   - `_maybe_inhibit` preserved `--repo` and `--no-inhibit`, but previously lost `--provider agy` and `--agy-print-timeout`.
   - Fixed to inspect and re-exec with `sys.argv[1:]` flags preserving provider identity and timeout settings across inhibit wrapping.
   - Tested under live `systemd-inhibit` foreground execution.

2. **P1-B — Immediate Fail-Closed Abort on Stream Identity Mismatch**:
   - Upstream AGY CLI streaming JSONL events are validated line-by-line during active streaming.
   - Any mismatched conversation ID in `init`, `step_update`, `result`, or `stderr` immediately terminates the provider child process tree via escalating `SIGINT` -> `SIGTERM` -> `SIGKILL`.
   - Zero state/checkpoint side effects; transitions cleanly to `FAILED` with `ErrorKind.STATE`.

3. **P1-C — Authoritative Quota Requirement at Preflight**:
   - Preflight supervisor checks now invoke authoritative quota checks without redundant or speculative probe runs.
   - Prevents unauthenticated turns from burning supervisor state; cleanly discriminates authentication vs. quota depletion.

4. **P2-High D — Durable Explicit Long-Turn Print Timeout**:
   - Upstream AGY defaults `--print-timeout` to 5 minutes (`5m0s`), which caused long agentic turns to be terminated prematurely.
   - Added durable `--agy-print-timeout` configuration (schema-persisted, validated range 5s–24h, default `"60m"` for AGY).
   - Watchdog timeout in supervisor is decoupled from quota exhaustion: classifies as `ErrorKind.CRASH` rather than quota error.

5. **P2-Med E — Provider-Aware Instruction Steering Transport**:
   - AGY CLI does not support upstream queue-based live steering in print mode (`agy --help` audited: no queue subcommand exists).
   - Steering (`queue_steer`, TUI `/steer`, CLI `nightwatch steer`) is now strictly provider-aware: returns an explicit, actionable refusal message:
     `"AGY live steering is not supported by the current upstream CLI; no instruction was sent."`
   - AGY conversation UUIDs are **NEVER** forwarded to `codex queue`.

6. **Owner-Approved Permission Policy Preservation**:
   - Maintained `--dangerously-skip-permissions` for unattended supervised AGY turns under `OWNER_APPROVED_UNATTENDED_AGY_PERMISSION_POLICY`.
